What changes

Everything moves. Nothing about your model does.

Photonics is an implementation detail we are happy to keep to ourselves. What reaches your codebase is a base URL and a much smaller power draw.

  • Same weights, same API

    Point an OpenAI-compatible client at Moiré. We compile your checkpoint to a photonic graph — you change a base URL, not a model.

  • Energy you can measure

    Every response carries the joules it cost. Read it per request, per token, or per team, and put a real number in the sustainability report.

  • Latency without a queue

    An optical path holds no state, so there is nothing to warm up and nothing to wait behind. Median first token lands in 3.2 ms.

  • Deterministic by default

    Each tenant gets its own wavelength allocation. The same prompt at the same seed returns the same tokens, run after run.
